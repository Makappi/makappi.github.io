# Makappi Website

Public website hosted on GitHub Pages at [makappi.com](https://makappi.com).

## Tech Stack

- **Template**: Sandbox - Bootstrap 5
- **Build Tool**: Gulp
- **Styles**: SCSS with autoprefixer and minification
- **HTML**: Partials via `gulp-file-include` (`@@include` syntax)
- **Dev Server**: BrowserSync (port 8080, live reload)
- **Languages**: English and French

## Project Structure

```
src/                  ← Source files (edit here)
  ├── assets/
  │   ├── scss/       ← Styles (SCSS)
  │   ├── js/         ← JavaScript
  │   ├── img/        ← Images (optimized on build)
  │   ├── fonts/      ← Font files
  │   ├── media/      ← Video and other media
  │   └── docs/       ← Downloadable documents
  ├── partials/       ← Reusable HTML partials
  ├── CNAME           ← Custom domain config
  └── *.html          ← Pages
docs/                 ← Built output (served by GitHub Pages)
```

**Important**: Only edit files in `src/`. The `docs/` folder is generated by the build and served directly by GitHub Pages.

## Getting Started

```bash
npm install
```

## Development

Start the dev server with live reload:

```bash
npm run dev
```

The website will be available at http://localhost:8080. Changes to files in `src/` trigger an automatic rebuild and browser refresh.

## Build

Build the production site into `docs/`:

```bash
npm run build
```

This compiles SCSS, minifies CSS/JS, optimizes images, processes HTML partials, and copies all assets to `docs/`.

## Deployment

The site is deployed via GitHub Pages serving the `docs/` folder. After building, commit the updated `docs/` folder and push to trigger deployment.

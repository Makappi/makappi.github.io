Comment proposer des codes promo dans votre App ?

  1. FAQ
  2. Codes promo dans votre App

Une réduction réservée à votre App est l'un des meilleurs moyens de pousser vos clients à la télécharger et à y commander. Cette page explique comment la mettre en place avec Makappi.

Shopify ne propose pas de codes promo « exclusifs à l'App »

Shopify ne permet pas de limiter un code promo à un canal de vente. Un code créé dans Shopify fonctionne partout : sur votre boutique en ligne, dans votre App et sur vos autres canaux. Aucun réglage ne permet de le rendre techniquement exclusif à l'App.

Bonne nouvelle : avec les outils de Makappi, vous pouvez obtenir un fonctionnement qui marche très bien en pratique. Le principe est simple : créer un code que vous ne promouvez que dans l'App, et laisser l'App l'appliquer pour vos clients, sans qu'ils aient jamais à le saisir.

1. Créez le code promo dans Shopify

Dans votre admin Shopify, allez dans « Réductions » et créez un code de réduction comme d'habitude (pourcentage, montant fixe, livraison offerte...).

  • Choisissez un code difficile à deviner. Évitez les noms évidents comme APP10 ou MOBILE : préférez par exemple APPX7K24
  • Ne le mentionnez nulle part ailleurs : ni sur votre site, ni dans vos newsletters, ni sur vos réseaux sociaux
  • Limitez-le à une utilisation par client et fixez une date de fin s'il s'agit d'une offre temporaire

2. Mettez-le en avant avec une bannière sur l'Accueil

Dans votre dashboard Makappi, allez dans « Design » > « Accueil » et ajoutez une Bannière, une Bannière Texte ou un Diaporama. Dans les réglages du bloc :

  • Activez « Ajouter un coupon au panier lors du clic »
  • Saisissez votre code promo dans le champ qui apparaît

Quand un client touche la bannière, le code est ajouté automatiquement à son panier. Votre bannière peut aussi renvoyer vers un produit ou une collection : le client arrive directement là où vous le souhaitez, avec la réduction déjà appliquée. Placez-la en haut de l'Accueil pour qu'elle soit vue dès l'ouverture de l'App.

Enregistrez et publiez la modification pour qu'elle arrive dans votre App.

3. Mettez-le en avant avec une notification push

Dans votre dashboard Makappi, allez dans « Marketing » > « Campagnes Push » et créez une nouvelle campagne. À l'étape du contenu, saisissez votre code dans le champ « Code promo » : il est appliqué automatiquement quand le client touche la notification.

Comme pour une campagne sans code, vous pouvez choisir une destination dans l'App (produit, collection ou page), l'envoyer tout de suite, la programmer, ou la faire arriver à la même heure locale pour tous vos clients.

Vous pouvez combiner les deux : une bannière sur l'Accueil pendant toute la durée de l'offre, et une notification push pour l'annoncer.

Un client peut-il utiliser le code sur la boutique en ligne ?

En théorie, oui. Comme le code est appliqué pour lui, le client n'a jamais besoin de le voir dans l'App, mais il apparaît dans le récapitulatif du paiement. Un client pourrait donc le noter et le réutiliser sur votre boutique en ligne.

En pratique, très peu de clients le font, surtout si le code est difficile à deviner, limité à une utilisation par client et jamais publié ailleurs. Ce fonctionnement fait le travail : votre offre reste une raison de télécharger et d'utiliser l'App.

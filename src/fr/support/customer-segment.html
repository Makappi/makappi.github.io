Identifier les clients de l’app : métachamp client et segments

  1. FAQ
  2. Métachamp client et segments

Identifiez les clients connectés à votre app grâce au métachamp client Makappi App User, et retrouvez ceux qui ont commandé depuis l’app avec les segments Shopify.

  • Utiliser le métachamp client Makappi App User
  • Retrouver les clients ayant commandé depuis l’app

Clients connectés à l’app : Makappi App User

Makappi renseigne automatiquement le métachamp client (Customer Metafield) Makappi App User pour identifier les clients connectés à leur compte dans l’app iOS ou Android, même s’ils n’ont pas passé commande.

Consulter le champ sur une fiche client

Dans Shopify, allez dans Clients, ouvrez une fiche client, puis retrouvez Makappi App User dans les Champs méta.

  • Vrai (true) : le client s’est connecté à son compte dans l’app. Le champ est aussi mis à jour lorsqu’il ouvre l’app avec une session existante.
  • Faux (false) : le champ est remis à faux lorsque le client se déconnecte explicitement de l’app, si la mise à jour peut être transmise.

Filtrer vos analyses dans Shopify Analytics

Le métachamp Makappi App User est aussi disponible dans les Filters (Filtres) de toutes les vues Shopify Analytics. Ajoutez ce filtre et sélectionnez Yes (Oui) pour analyser les données des clients identifiés dans l’app, ou No (Non) pour ceux dont le champ est à faux.

Créer un segment à partir de ce champ

  1. Allez dans Clients → Segments → Créer un segment.
  2. Dans les filtres du segment, recherchez le métachamp Makappi App User et choisissez la valeur vrai (true).
  3. Enregistrez le segment, par exemple sous le nom Clients connectés à l’app. Vous pourrez ensuite l’exporter comme décrit plus bas.

Ce segment permet de retrouver les clients identifiés dans l’app, y compris ceux qui n’ont encore passé aucune commande.

Ce champ est un indicateur approximatif : il ne couvre pas les visiteurs non connectés et ne permet pas de compter les installations. Une désinstallation ou l’utilisation de plusieurs appareils peut laisser une valeur qui ne reflète pas la situation actuelle. Les clients déjà connectés sont pris en compte progressivement à leur prochaine ouverture d’une version de l’app compatible.

Clients ayant commandé depuis l’app

Créez un segment de clients Shopify pour retrouver les clients ayant passé au moins une commande via le canal de vente Makappi. Vous pourrez ensuite exporter cette liste si besoin.

1. Ouvrir les segments de clients

Dans votre administration Shopify, allez dans Customers → Segments (Clients → Segments), puis cliquez sur Create segment (Créer un segment).

2. Décrire les clients à retrouver

Copiez la phrase ci-dessous et collez-la dans le champ de description du segment. Puis cliquez sur la flèche à droite. Conservez cette phrase en anglais, comme dans la capture.

Customers who placed orders created by the app 'Makappi, Mobile App Builder'.

3. Enregistrer le segment généré

Shopify génère la requête et affiche les clients correspondants. Vérifiez que la description concerne les clients ayant passé des commandes via Makappi, puis cliquez sur Save (Enregistrer).

Le segment peut être vide si aucun client ne correspond encore. Il se met à jour automatiquement lorsque des clients passent commande via Makappi.

4. Nommer votre segment

Saisissez un nom, par exemple Clients ayant commandé depuis l’app, puis cliquez sur Save (Enregistrer).

5. Exporter la liste des clients (facultatif)

Une fois le segment enregistré, ouvrez More actions → Export (Autres actions → Exporter) pour exporter la liste des clients.

Comment intégrer Flits Wishlist ?

  1. FAQ
  2. Intégrations
  3. Comment intégrer Flits Wishlist ?

Intégrez Flits dans votre Application Mobile pour partager la liste de souhaits entre votre site et l'app : vos clients retrouvent la même liste partout, dès qu'ils sont connectés.

Créer une clé API Flits

L'intégration utilise une clé API Flits que vous pouvez créer vous-même, directement depuis l'app Flits.

  • Dans votre admin Shopify, ouvrez l'app "Flits"
  • Allez dans "Settings" > "API Keys"
  • Cliquez sur "Create API Key", nommez la clé "Makappi", puis cliquez sur "Generate"
  • Copiez la clé générée : elle n'est affichée qu'une seule fois, juste après sa création

Connecter Flits à votre Application Mobile

  • Dans votre dashboard Makappi, allez dans "Réglages" > "Intégrations" et sélectionnez "Flits Wishlist"
  • Activez l'intégration et collez la clé dans le champ "Token d'API"
  • Cliquez sur "Tester la connexion" pour vérifier que la clé fonctionne
  • Enregistrez et publiez les changements pour terminer l'intégration

Ce que vos clients voient dans l'app

  • Les clients connectés à leur compte boutique retrouvent leur liste de souhaits Flits dans l'app
  • Les produits ajoutés à la liste depuis l'app apparaissent aussi sur votre site, et inversement

Dépannage

  • Le token est refusé : vérifiez que vous avez copié la clé en entier, sans espace avant ou après. Au besoin, créez une nouvelle clé dans l'app Flits et réessayez.
  • La liste de souhaits ne s'affiche pas dans l'app : le client doit être connecté à son compte boutique dans l'app.
  • Autre problème : contactez-nous à support@makappi.com.

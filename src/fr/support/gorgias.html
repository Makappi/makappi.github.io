  2. Gorgias

L'intégration Gorgias permet d'intégrer un chat en direct dans votre App, afin que vos clients puissent contacter votre support sans quitter l'application.

Configuration

Pour activer l'intégration Gorgias, rendez-vous dans Settings > Integrations dans le Backoffice Makappi et renseignez votre Application ID Gorgias.

Comment trouver votre Application ID Gorgias

Pour trouver votre Application ID, suivez ces étapes dans votre tableau de bord Gorgias :

  1. Allez dans Settings et sélectionnez Chat dans la section Channels
  2. Choisissez le widget Chat que vous souhaitez connecter
  3. Allez dans Installation > Manual Installation > Google Tag Manager
  4. Votre Chat Application ID sera affiché à l'étape 4

Ajouter le chat à votre menu

Pour rendre le chat Gorgias accessible à vos clients, un lien "Contact" peut être ajouté au menu de votre App. Contactez-nous à support@makappi.com et nous l'ajouterons pour vous.

  3. Comment intégrer JudgeMe ?

Intégrer JudgeMe dans votre Application Mobile permet à vos clients de consulter les avis sur les produits.

Ajout du token API

  • Dans JudgeMe, rendez-vous dans Settings
  • Cliquez sur Integration
  • Cliquez sur le bouton View API Token (en haut à droite)
  • Dans la pop-up, copiez le Public API token et le Shop domain
  • Collez ces deux valeurs dans les paramètres de l'intégration JudgeMe sur Makappi (Public Token + Shop domain)

Comment configurer les liens universels sur iOS et Android ?

  1. FAQ
  2. Liens universels

Les liens universels sur iOS et les App Links sur Android associent le domaine personnalisé de votre boutique Shopify à votre application mobile. Lorsqu'un client ouvre un lien comme votreboutique.com, votre App s'ouvre automatiquement si elle est installée. Sinon, le lien ouvre votre boutique en ligne.

Les liens profonds sont également pris en charge : les liens vers des produits, des collections et d'autres pages compatibles ouvrent directement le contenu correspondant dans l'App.

Prérequis

  • Votre boutique Shopify doit utiliser un domaine personnalisé. Un domaine *.myshopify.com ne peut pas être utilisé pour cette configuration.
  • Contactez le support Makappi pour obtenir les informations suivantes :
    • iOS : identifiant Apple de l'App (Apple App ID)
    • Android : identifiant de l'application (Application ID) et empreinte SHA-256 du certificat de signature

Configurer l'application personnalisée dans Shopify

1. Ouvrez les paramètres de développement d'applications

Dans l'interface d'administration Shopify, accédez à Paramètres > Applications et canaux de vente > Développer des applications.

2. Autorisez le développement d'applications personnalisées héritées si nécessaire

Si Shopify affiche cette option, sélectionnez Allow legacy custom app development. Si ce message n'apparaît pas, créez directement une application et passez à l'étape 5.

3. Confirmez le développement d'applications personnalisées

Sélectionnez Allow custom app development.

4. Créez une application personnalisée héritée

Sélectionnez Create a legacy custom app.

5. Nommez et créez l'application

Saisissez Makappi comme nom de l'application, puis sélectionnez Create app.

6. Configurez les autorisations de l'API Storefront

Sélectionnez Configure Storefront API scopes.

7. Autorisez la lecture des fiches produits

Sélectionnez unauthenticated_read_product_listings dans la liste des autorisations, puis sélectionnez Save.

8. Installez l'application

Après avoir enregistré l'autorisation, sélectionnez Install app.

9. Confirmez l'installation

Sélectionnez Install dans la fenêtre de confirmation.

Configurer iOS et Android

10. Modifiez l'intégration de l'API Storefront

Ouvrez l'onglet Configuration, puis sélectionnez Edit dans la section Storefront API integration.

11. Saisissez les identifiants iOS et Android

Faites défiler la page jusqu'aux sections iOS et Android, puis saisissez les informations fournies par le support Makappi :

  • iOS : saisissez l'Apple App ID et cochez Use iOS universal links ainsi que Use iOS web credentials.
  • Android : saisissez l'Application ID Android et l'empreinte SHA-256 du certificat de signature.

12. Enregistrez la configuration

Remontez en haut de la page, puis sélectionnez Save.

Tout est prêt ! Votre domaine personnalisé peut maintenant ouvrir l'App installée et rediriger les clients vers les contenus compatibles.

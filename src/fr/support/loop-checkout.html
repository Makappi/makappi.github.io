Configurer Loop Checkout+

  1. FAQ
  2. Intégrations
  3. Configurer Loop Checkout+

Vos clients peuvent choisir Checkout+ dans le panier de l’app pour payer une couverture des retours.

1. Vérifier la configuration Loop

Demandez à votre interlocuteur Loop d’activer Returns Coverage Enabled et de confirmer la création du produit Checkout+. Utilisez ce produit, sans en créer un autre. L’option Checkout+ New Extension n’est pas nécessaire pour cette intégration.

2. Publier le produit dans Shopify

Ouvrez le produit Checkout+ dans Shopify > Produits. Vérifiez son statut Actif, ajoutez Makappi dans les canaux de vente de la rubrique Publication, puis enregistrez. Vérifiez sa disponibilité sur les marchés où votre app vend.

3. Activer l’intégration Makappi

Dans Makappi > Paramètres > Intégrations, activez Loop Checkout+, enregistrez et publiez votre configuration. L’app récupère automatiquement le produit et son prix. Aucun identifiant produit ni clé API à saisir.

4. Vérifier le parcours d’achat

Testez le panier avec et sans Checkout+. Si vous utilisez des tags d’exclusion dans Loop, testez aussi un panier exclu. Si l’offre n’apparaît pas, vérifiez les étapes ci-dessus ou contactez Loop.

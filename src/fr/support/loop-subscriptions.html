Configurer Loop Subscriptions

  1. FAQ
  2. Intégrations
  3. Loop Subscriptions

Connectez Loop Subscriptions à Makappi pour permettre aux clients de choisir un abonnement sur les produits éligibles dans votre app.

1. Vérifier le produit dans Shopify

Configurez son abonnement dans Loop. Dans Shopify, vérifiez que le produit est actif, en stock et disponible sur le canal de vente Makappi.

2. Générer un token API Loop

Dans Loop, ouvrez Settings > Admin > API tokens, puis cliquez sur Generate New Token (ou Generate Token si la liste est vide).

Saisissez Makappi comme nom. Cochez uniquement Customers avec le droit Read & write, puis cliquez sur Generate.

Copiez le token API généré et gardez-le confidentiel. Le droit Loop Selling Plans n’est pas nécessaire : Makappi lit les plans d’achat dans Shopify.

3. Publier l’intégration Makappi

Dans Makappi, ouvrez Settings > Integrations > Loop Subscriptions, cliquez sur Enable integration, collez le token dans API token, puis cliquez sur Publish Changes en haut de la page. Vous pouvez saisir le token avant cette première publication. Le champ conserve la valeur enregistrée pour la consulter ou la remplacer ensuite.

Le token reste sur le serveur Makappi et n’est pas inclus dans la configuration envoyée aux apps mobiles.

4. Vérifier le parcours d’achat

Ouvrez un produit éligible dans votre app, choisissez un abonnement et vérifiez que le plan et son prix restent dans le panier jusqu’au paiement Shopify.

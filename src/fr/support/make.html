Comment créer des campagnes push avec Make ?

  1. FAQ
  2. Intégrations
  3. Make

L'intégration Make permet à vos scénarios Make de créer des campagnes de notifications push dans votre app : une nouveauté, une meilleure vente repérée dans vos commandes payées, un retour en stock... Chaque campagne peut avoir une image, ouvrir un produit, une collection ou un lien, et être enregistrée en brouillon, programmée ou envoyée immédiatement.

Les campagnes créées par Make apparaissent dans votre liste de campagnes Makappi, comme celles que vous créez vous-même. Elles sont envoyées à tous les utilisateurs de l'app qui ont accepté les notifications.

L'intégration Make est disponible dans les plans Premium et Custom. Elle est activée par l'équipe Makappi : contactez-nous pour l'activer.

Étape 1 : récupérer votre clé API

  • Dans votre tableau de bord Makappi, allez dans Paramètres > Intégrations > Make
  • Copiez l'adresse de l'API et la clé API
Gardez cette clé secrète : elle donne accès à vos campagnes push. En cas de fuite, cliquez sur Régénérer la clé API : l'ancienne clé cesse immédiatement de fonctionner et vous devrez mettre à jour vos scénarios.

Étape 2 : ajouter un module HTTP dans Make

Dans votre scénario, ajoutez le module HTTP > Make a request et configurez-le :

  • URL : https://app.makappi.com/api/v1/push-campaigns
  • Method : POST
  • Headers : nom Authorization, valeur Bearer VOTRE_CLE_API
  • Body type : Raw, Content type : JSON (application/json)
  • Parse response : Yes

Remplissez ensuite le champ Request content avec votre campagne, à partir des données des modules précédents (par exemple un produit Shopify) :

{
  "externalId": "new-arrival-8123456789",
  "status": "DRAFT",
  "title": {"en": "New arrival", "fr": "Nouveauté"},
  "message": {"en": "Discover the Blue shirt", "fr": "Découvrez la chemise bleue"},
  "imageUrl": "https://cdn.shopify.com/s/files/.../blue-shirt.jpg",
  "destination": {"type": "PRODUCT", "productId": "8123456789", "productTitle": "Blue shirt"}
}

Champs de la campagne

  • title et message (obligatoires) : un texte, ou un texte par langue comme {"en": "...", "fr": "..."}. Chaque utilisateur reçoit sa langue, ou l'anglais par défaut. Titre : 200 caractères maximum, message : 1000.
  • status : DRAFT (par défaut, enregistrée sans être envoyée, à relire dans Makappi), SCHEDULED (envoyée à la date sendAt) ou NOW (envoyée immédiatement).
  • sendAt : date d'envoi au format ISO 8601, par exemple 2026-11-02T18:00:00Z. Obligatoire avec SCHEDULED, et dans le futur. La campagne est envoyée à cette heure précise pour tout le monde.
  • imageUrl : l'URL https d'une image affichée dans la notification (push enrichie).
  • destination : ce qui s'ouvre quand on touche la notification.
    • {"type": "PRODUCT", "productId": "...", "productTitle": "..."}
    • {"type": "COLLECTION", "collectionId": "...", "collectionTitle": "..."}
    • {"type": "LINK", "url": "https://..."}
    • {"type": "NONE"} (par défaut) : ouvre l'app
    Les identifiants Shopify peuvent être numériques (8123456789) ou complets (gid://shopify/Product/8123456789). Les titres sont facultatifs et ne s'affichent que dans votre tableau de bord.
  • discountCode : un code promo appliqué au panier à l'ouverture de la notification.
  • externalId : votre propre identifiant unique pour cette campagne (voir ci-dessous). Recommandé.

Éviter les campagnes en double

Un scénario peut s'exécuter deux fois sur les mêmes données (nouvelle tentative, relance, deux déclencheurs). Envoyez toujours un externalId construit à partir de vos données, par exemple new-arrival-{{id du produit}} ou best-seller-2026-11-02. Si une campagne avec le même externalId existe déjà, aucune nouvelle campagne n'est créée : l'API renvoie la campagne existante avec "created": false.

Réponse

Une nouvelle campagne renvoie le code 201, une campagne existante (même externalId) le code 200 :

{
  "created": true,
  "campaign": {
    "id": "5f535f0b-4d31-4d17-820c-06411031c114",
    "externalId": "new-arrival-8123456789",
    "status": "DRAFT",
    "title": {"en": "New arrival", "fr": "Nouveauté"},
    "message": {"en": "Discover the Blue shirt", "fr": "Découvrez la chemise bleue"},
    "imageUrl": "https://cdn.shopify.com/s/files/.../blue-shirt.jpg",
    "destination": {"type": "PRODUCT", "productId": "gid://shopify/Product/8123456789", "productTitle": "Blue shirt"},
    "discountCode": null,
    "sendAt": null,
    "deliveryStats": null,
    "createdAt": "2026-10-28T20:13:16.683Z",
    "updatedAt": "2026-10-28T20:13:16.683Z"
  }
}

Conservez l'id pour consulter, programmer ou annuler la campagne plus tard.

Autres opérations

Elles utilisent la même URL et le même en-tête Authorization. Elles ne concernent que les campagnes créées par l'API.

  • Consulter une campagne : GET /api/v1/push-campaigns/{id}. Renvoie son statut et, une fois envoyée, ses statistiques deliveryStats.
  • Lister les campagnes : GET /api/v1/push-campaigns, les plus récentes d'abord. Filtres facultatifs : ?externalId=..., ?status=DRAFT, ?limit=50 (100 maximum).
  • Programmer ou envoyer un brouillon : POST /api/v1/push-campaigns/{id}/schedule avec {"sendAt": "2026-11-02T18:00:00Z"}, ou un corps vide {} pour l'envoyer tout de suite.
  • Annuler une campagne : POST /api/v1/push-campaigns/{id}/cancel. Une campagne programmée ou en cours d'envoi repasse en brouillon. Les notifications déjà reçues ne peuvent pas être retirées.
  • Supprimer un brouillon : DELETE /api/v1/push-campaigns/{id}.

Statuts des campagnes

  • DRAFT : enregistrée, non envoyée
  • SCHEDULED : en attente de sendAt
  • NOW : en file pour un envoi immédiat
  • PENDING : en cours d'envoi
  • SENT : envoyée

Erreurs et limites

Les erreurs renvoient un message qui explique le problème : {"error": {"code": "...", "message": "..."}}.

  • 400 : champ invalide (le message indique lequel)
  • 401 : clé API absente ou invalide
  • 403 : l'intégration Make n'est pas activée
  • 404 : campagne introuvable
  • 409 : opération impossible dans le statut actuel (par exemple supprimer une campagne programmée)
  • 429 : plus de 10 campagnes créées en une minute

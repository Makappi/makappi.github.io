Comment intégrer Smile ?

  3. Comment intégrer Smile ?

Intégrez Smile dans votre Application Mobile pour que vos clients puissent voir leur nombre de points de fidélité et récupérer leurs récompenses directement dans l'app.

Connecter votre compte Smile

L'intégration se configure avec un simple bouton "Connecter avec Smile" — sans clé API et sans abonnement Smile particulier.

  • Dans votre dashboard Makappi, allez dans "Réglages" > "Intégrations" et sélectionnez "Smile"
  • Activez l'intégration, puis cliquez sur "Connecter avec Smile"
  • Une page Smile s'ouvre dans un nouvel onglet : connectez-vous si nécessaire et autorisez Makappi à accéder à votre compte Smile
  • De retour dans le dashboard, l'intégration Smile affiche un badge "Connecté"
  • Enregistrez et publiez les changements pour terminer l'intégration

Ce que vos clients voient dans l'app

  • Les clients connectés à leur compte boutique voient leur solde de points Smile
  • Ils peuvent parcourir les récompenses que vous avez configurées dans Smile
  • Ils peuvent échanger leurs points contre une récompense : l'app affiche le code de réduction à utiliser au moment du paiement

Dépannage

  • Les points ne s'affichent pas dans l'app : le client doit être connecté à son compte boutique dans l'app, et doit déjà être membre Smile sur votre boutique (Smile crée les membres à l'inscription ou à la première commande).
  • Aucune récompense listée : vérifiez que des "Points products" (façons d'échanger les points) sont configurés et actifs dans votre admin Smile.
  • La connexion a échoué ou a été refusée : retournez dans "Réglages" > "Intégrations" > "Smile" et cliquez à nouveau sur "Connecter avec Smile".
  • L'intégration ne fonctionne plus : cliquez sur "Déconnecter" puis "Connecter avec Smile" pour reconnecter votre compte. Si le problème persiste, contactez-nous à support@makappi.com.

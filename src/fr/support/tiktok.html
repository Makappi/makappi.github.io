TikTok

  1. FAQ
  2. TikTok

L'intégration TikTok envoie les événements de votre app à TikTok : vos campagnes publicitaires TikTok peuvent ainsi mesurer les installations et les achats, et s'optimiser dessus. Elle nécessite une source de données d'app dans TikTok Events Manager pour chaque plateforme (iOS et Android).

Créer les sources de données d'app

  1. Dans TikTok Ads Manager, ouvrez Outils > Événements (Events Manager).
  2. Ajoutez votre app iOS comme source de données d'app, avec le TikTok App Events SDK comme méthode de connexion. Recommencez pour votre app Android : chaque plateforme a sa propre source de données et son propre TikTok App ID.
  3. TikTok vous demande les informations de votre app sur les stores : l'ID et l'URL App Store pour iOS, le nom du package et l'URL Google Play pour Android. Elles sont disponibles dans le Backoffice Makappi, prêtes à copier, dans Paramètres > Intégrations > TikTok App Events.

Identifiants à saisir dans Makappi

Dans le Backoffice Makappi, ouvrez Paramètres > Intégrations > TikTok App Events et renseignez, pour chaque plateforme :

  • TikTok App ID : affiché dans les détails de la source de données d'app dans Events Manager (TikTok l'envoie aussi par email à la création de la source).
  • App Secret : disponible dans les paramètres de la source de données d'app dans Events Manager.

Une plateforme dont les identifiants sont incomplets n'envoie aucun événement, et l'app continue de fonctionner normalement. Les nouveaux réglages sont appliqués au prochain lancement de l'app.

Événements envoyés à TikTok

L'app envoie les événements standards TikTok : consultation d'un produit (ViewContent), ajout au panier (AddToCart), ajout aux favoris (AddToWishlist), début du paiement (Checkout), achat (Purchase, avec montant et devise) et création de compte (Registration). Le SDK remonte aussi les installations et les lancements de l'app. Les produits sont identifiés par l'ID de variante Shopify.

Sur iOS, les événements ne sont associés à l'identifiant publicitaire que si l'utilisateur accepte la demande de suivi de l'app. Vous pouvez vérifier la réception des événements dans Events Manager > Test Events.

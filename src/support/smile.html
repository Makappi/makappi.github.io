How to integrate Smile?

  1. FAQ

  3. How to integrate Smile?

You can add Smile to your Mobile App your clients will be able to see their points and redeem coupons.

Smile compatible plans

To add Smile to your Mobile App, you need to be on the Smile "Plus" plan. You can contact Smile to learn more about API access.

Add the API key

  • On your Shopify Admin, go to the Smile App
  • Go to "Settings" > "Developer Tools", then click on "Manage API Keys"
  • Generate a new API key for your Mobile App and include all scopes
  • Copy this API key in the Makappi backoffice and publish the change to finish the integration
